# Build the Best AI Coding Agent from Scratch

A comprehensive, dependency-ordered, teaching-voice guide that takes any developer from zero to a fully-featured terminal AI coding agent.

**32 chapters · 6 sections · Built layer by layer**

## What this is

A step-by-step guide to building a production-grade AI coding agent from scratch. You'll build every layer — the unified LLM streaming API, the agent loop with tool execution, context compaction, a terminal UI engine, and the complete CLI. Every chapter includes complete, runnable TypeScript code.

## Who this is for

Students and junior developers who want to understand how AI agents work by building one. You need TypeScript and basic terminal familiarity — no AI/ML background required.
